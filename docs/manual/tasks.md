# Задачи и согласования

Страница: `/tasks`. Здесь отображаются задачи, назначенные пользователю при выполнении бизнес-процессов: подготовка результата, согласование и уведомления с подтверждением.

## Работа с задачей

1. Откройте раздел и нажмите «Обновить», если ожидаемая задача ещё не появилась.
2. Прочитайте название, тип и связь с процессом. Откройте тикет, если для него предоставлен доступ.
3. Выполните доступное действие: завершите задачу, согласуйте/отклоните решение или подтвердите уведомление.
4. Дождитесь сохранения. Продолжение процесса выполняет серверный обработчик, а не открытая вкладка браузера.

Ответственность задаётся в определении процесса. Оператор не может решить задачу другого назначенного сотрудника только потому, что видит общий список. Администратор действует в пределах серверных правил управления процессом.

## Доступ к чужому обращению

Назначенная задача может быть доступна сотруднику, которому не разрешён весь тикет. В таком случае сервер возвращает ограниченные сведения задачи и не открывает переписку или вложения. Кнопка перехода к тикету не должна интерпретироваться как выдача новых прав.

## Повторы и завершение процесса

Решение сохраняется в БД. Повторное действие не должно повторно продвигать уже завершённый шаг. Для параллельных согласований существуют отдельные задачи; общий шаг завершения ждёт необходимые ветви. Невыполненные задачи отменяются при терминальной ошибке или отмене процесса. Уведомление, сформированное завершившимся процессом, остаётся доступным для подтверждения.

API: `GET /api/v1/workflow-tasks`, `POST /api/v1/workflow-tasks/{id}`. Формат допустимого решения зависит от типа задачи; интерфейс показывает подходящие действия.
