# Проверка API

Страница: `/settings/api-check`. Симулятор помогает проверить приём внешнего сообщения через общий ingest-контур.

## Запуск

Выберите канал, укажите отправителя, тему и текст. Можно подставить один из подготовленных примеров. Нажмите «Отправить через Ingest API» и изучите ответ интеграции.

В отличие от «Проверки ответов», этот инструмент вызывает путь создания обращения. Используйте тестовые данные и учитывайте, что в рабочем пространстве появится тикет. Пример финансового вопроса — демонстрационный текст, а не платёжная операция.

## Что проверять

Проверьте назначение отдела, приоритет, обработку одинакового отправителя, наличие уточнений и итоговую запись в очереди. Повторная доставка с одним ключом не должна создавать вторую независимую заявку. Изменённое тело под прежним ключом должно рассматриваться как конфликт, а не новое обращение.

Нормализованный канал не доказывает реальную доставку через Telegram или Email. Тест из симулятора не заменяет проверку живого бота, IMAP и SMTP.

API: `POST /api/v1/ingest` с предусмотренной авторизацией. Ключи и origin проверяются отдельно от содержимого сообщения.
