# Каналы связи

Страница: `/settings/connections`. Нужны права администратора и управления интеграциями.

## Telegram и MAX

Укажите токен соответствующего бота. «Проверить связь» проверяет реквизиты; «Сохранить и перезапустить канал» сохраняет конфигурацию и перезапускает обслуживающий канал. «Отключить канал» прекращает его работу для компании.

Получите токен у соответствующей платформы и используйте отдельного бота организации. Токен не является адресом пользователя и не должен попадать в сообщение сотруднику. При повторном открытии настроек API не возвращает сохранённый секрет целиком.

Для связи с сотрудником используется подтверждённая привязка из меню профиля. Пока связь не установлена, технический отправитель канала не доказывает принадлежность конкретному профилю. Один тикет хранит общую историю сообщений сайта и связанных каналов.

## Email

Укажите адрес почтового ящика, пароль приложения и поддерживаемые параметры IMAP/SMTP. Проверьте доступность серверов из среды, в которой работает приложение. Успешная проверка реквизитов не заменяет правильную настройку исходящей почты и правил провайдера.

Не используйте обычный пароль от личной почты, если провайдер выдаёт отдельные пароли приложений. Подключённая почта обрабатывает обращения, но не означает наличие автоматической рассылки приглашений или регулярных отчётов.

## Обработка и доставка

Входящие сообщения нормализуются в общий формат обращения. За повторные доставки отвечает механизм идемпотентности. Ответ сохраняется в тикете, а доставка во внешний канал выполняется через отдельный механизм с фиксацией состояния и повторными попытками.

Если сообщение не дошло, сначала проверьте историю тикета и состояние канала. Повторное нажатие без изменения текста не должно создавать новый независимый ответ. Ошибка внешнего сервиса не должна раскрывать токен в интерфейсе.

API: `/api/v1/settings/channels`, `DELETE /channels/{channel}`, `POST /channels/{channel}/check` под префиксом `/api/v1/settings`. Состояние и разрешённые реквизиты ограничены текущей компанией.
