## Подтверждённые проблемы и исправления JS

### P1 — потеря несохранённых данных при возврате в раздел

`web/operations.js` заново вызывал редакторы с пустой записью при каждом refresh разделов workflows/assets/reports. `web/platform.js` скрывал и перезаполнял форму организации. `web/governance.js` перерисовывал одновременно роли, формы, маршруты и настройки ИИ.

Добавлена защита изменённых редакторов, в том числе от ответа запроса, начатого до ввода. При чистом редакторе сохраняется выбранная запись. Governance учитывает изменённость отдельно для роли, назначения, формы, маршрутов/SLA и ИИ: сохранение одного блока не сообщает, что все остальные изменения уже сохранены. Сохранение роли обновляет селекторы, не уничтожая другие редакторы.

### P1 — скрытый URL блокировал сохранение шага workflow

`web/operations.js`: неподходящие для типа шага поля скрывались, но оставались участниками нативной валидации формы. После незавершённого HTTP-адреса и смены типа шага браузер мог блокировать сохранение невидимым контролом.

Скрытые controls теперь отключаются и включаются вместе с видимостью. Данные шага по-прежнему собираются и проверяются существующими правилами.

### P1 — вставка Copilot уничтожала ручной ответ

`web/copilot.js`: действие вставки безусловно заменяло содержимое поля ответа. Теперь черновик добавляется после существующего текста, а повторное вставление того же окончания не дублирует его. Сохраняются событие input и фокус для работы штатного редактора.

### P1 — обновление формы теряло значения и выбранный файл

`web/intake-custom-fields.js`: повторная загрузка той же схемы удаляла все созданные controls. Теперь сохраняются совместимые значения и исходный file-input, чтобы выбранный файл оставался выбранным. При переключении на другую именованную форму перенос полей не выполняется. Удалённые/изменившие тип поля не восстанавливаются насильно.

Добавлены понятная ошибка FileReader и клиентская проверка суммарных 5 МиБ вложений. Серверная проверка остаётся обязательной.

### P1 — виджет перемещал фокус в закрытую панель

`web/widget.js`: завершение сетевого запроса всегда фокусировало textarea, даже после закрытия. Теперь фокус возвращается в поле только у открытого чата. Закрытие кнопкой или Escape возвращает фокус launcher; его aria-expanded и aria-controls соответствуют состоянию.

### P2 — бренд и читаемость внешнего виджета

`web/widget.js`: вместо декоративной звезды используются существующие изображения логотипа в launcher и шапке. Добавлена белая подложка; базовый цвет приведён к #0b5367. Пользовательский цвет сохраняется, а цвет текста выбирается по относительной яркости. Улучшены размер кнопки закрытия, подпись FlowOps, маленькая высота viewport и reduced motion.
