# Organization registration and request flow

Mode: Operate. Employees use a familiar navy/teal workspace at a desk or on a phone. Preserve Golos Text and existing role boundaries.

## Direction contract

THESIS: help a person start with a concrete situation, then keep the clarification and outcome in one request.

OWN-WORLD: white working panels, navy text, teal actions, restrained borders and generous separation. Existing theme tokens and local fonts remain authoritative.

STORY: choose a relevant scenario or write freely; supply missing context; receive a regulation or a specialist response and return through personal history.

FIRST VIEWPORT: a task heading, three sequential steps, three domain examples, then a primary request form with result and history alongside it. Mobile stacks the same content.

FORM: extension of the established employee and operator surfaces; seed: none (pinned), “сценарии перед формой, три этапа обращения, оформление результата, истории и очереди оператора”.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

## Behavior

Registration accepts education, bakery, bank and other. An omitted type remains compatible with old clients and selects other. A new workspace receives its own builder settings, widget greeting and two or three Markdown starter documents. Every document is explicitly a template to adapt. Existing workspaces receive only a type default during migration; their settings and documents are preserved.

The profile exposes the selected domain examples and current departments. Operator assignment, filters and knowledge forms use those departments, including custom departments configured later. The university demonstration guides remain scoped to the existing default workspace.
