# URL разделов

Страницы поддерживают прямой переход, обновление и историю браузера. Проверка доступа к данным остаётся на сервере; URL не выдаёт права. После входа открывается запрошенный доступный раздел, иначе разрешённый раздел текущей роли.

| URL | Раздел |
|---|---|
| `/requests` | Подача и собственные обращения |
| `/tickets` | Очередь обращений |
| `/tickets/41` | Тикет по ID |
| `/tasks` | Задачи и согласования |
| `/analytics` | Аналитика |
| `/analytics/processes` | Аналитика процессов |
| `/optimization` | Центр оптимизации |
| `/reports` | Регулярные отчёты |
| `/notifications` | Уведомления SLA |
| `/administration` | Участники и доступы |
| `/settings/1c` | Подключение 1С |
| `/settings/workflows` | Бизнес-процессы |
| `/settings/assets` | Объекты и QR |
| `/settings/governance` | Права и процессы |
| `/settings/structure` | Структура организации |
| `/settings/organization` | Организация и SLA |
| `/settings/knowledge` | База знаний |
| `/settings/connections` | Каналы связи |
| `/settings/communication` | Отделы и общение |
| `/settings/import` | Импорт регламентов |
| `/settings/preview` | Проверка ответов |
| `/settings/widget` | Виджет сайта |
| `/settings/api` | API-ключи |
| `/settings/api-check` | Проверка API |

`/` остаётся точкой входа и выбирает стартовый раздел роли. QR `/?asset=...` сохраняет контекст при переходе к форме `/requests?asset=...`. Переход в другие разделы удаляет этот параметр из адреса.

Клиентская карта — `web/routes.js`, серверные страницы — `cmd/server/routes.go`. Тесты проверяют соответствие навигации карте и загрузку HTML оболочки для всех страниц. Новые API 1С описаны в [ONEC.md](ONEC.md).

## Публичная справка

`/documentation` — руководство; `/documentation/{slug}` — отдельная глава; `/license` — лицензия с полным текстом Apache 2.0; `/license.txt` — исходный LICENSE; `/third-party-notices.txt` — уведомления и лицензии зависимостей. Эти страницы доступны без сеанса и не открывают данные компаний.
