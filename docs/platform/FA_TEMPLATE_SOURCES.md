# Financial University template evidence — 2026-11-28

The platform now includes a separate `financial_university` registration template. It uses the same runtime, permissions, settings and knowledge lifecycle as every other organization. It is explicitly a demonstration configuration and declares no working integration with university systems.

Confirmed naming from indexed official pages:

| Template queue | Confirmed name | Official source |
|---|---|---|
| IT | Дирекция цифровых технологий | [Official unit page](https://www.fa.ru/university/structure/university/dct/) |
| HR | Управление кадрового обеспечения | [Official unit page](https://www.fa.ru/university/structure/university/ko/) |
| Accounting | Управление бухгалтерского учета и отчетности | [Official unit page](https://www.fa.ru/university/structure/university/buio/) |

Direct requests to some official pages returned HTTP 403; naming was checked against the web index of the official pages. No person names, telephone numbers or email addresses were copied into the template. These sources establish unit naming, not a confirmed service routing contract or SLA.

An official [business-trip PDF](https://www.fa.ru/upload/iblock/5b8/jjhz83f0358orfhvm4qgu1hmqeo1ag6h/Polozhenie-o-sluzhebnykh-komandirovkakh.pdf) was identified. Its current applicability and version must be confirmed before adopting rules. Monetary norms, deadlines and approval chains from it were deliberately not placed in autoanswers.

Facilities, document handling, cross-unit approval and student queues are marked demonstration queues, not official unit names. The nine initial guides cover employee access/equipment/HR/business travel/advance reporting/document handling/facilities/approval and student support. Every seeded guide explicitly requires organizational adaptation. There are no claimed external integrations, approved workflow signatures or invented university deadlines.

Registration copies a public template snapshot into the workspace; runtime departments and templates are separately stored in app_settings. Later changes to the template catalog do not reseed an existing tenant or replace edited rules. Additional IT/manufacturing/retail/medical/logistics templates and a no-starter-content option use the same mechanism. Medical template content is administrative support only, with no clinical advice.
